# draft-handover

Re-score first and review prioritise. Write an internal handover in drafts. Never send, enrol contacts in sequences or infer contact permission.

```bash
npm run qualify -- draft-handover --actor="<operator>"
```

Use --json when needed. Present the result and its missing evidence. Stop if a name is ambiguous; show the candidates.
