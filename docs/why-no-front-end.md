# Why this desk has no front end

The recurring jobs are reviewing evidence, changing explicit rules and preparing a handover. The CLI handles those jobs; HTML records let a colleague read the result.

A live application gives teams shared forms, authenticated permissions, mobile capture, alerts and immediate updates. This base has none of those. The operator records observed events or imports authorised exports, then runs the review. There is no visitor tracker or live CRM connection. Screens and connections can be built for the business's version through Omni by Enterprise DNA.
